# 08 — Version-1 release gate

Complete all accepted version-1 features before group testing. CCNP branches remain future content. An owner-only development preview is not a group release.

Required evidence:

1. Complete reviewed official CCNA objective matrix and realistic mock-format verification, with all knowledge/practical mastery rules.
2. Solvability coverage and consistent state/output for supported protocols, physical interactions and engineering projects.
3. Native iPhone/iPad/Android installed-PWA tests for cold offline launch, storage pressure, calls, backgrounding, timers, keyboard, screen reader, rotation and enlarged text.
4. Real authenticated invite/OTP/recovery flows and owner-only authorization/publication permissions.
5. Multi-user concurrency, leases, takeover, offline forks, conflict review, score deduplication, embargo and privacy tests with 2–4 participants and up to 10 learners.
6. Release migration/rollback, encrypted backup recovery, storage budgeting, notification consent/quiet hours and quota-degradation behavior.
7. Free-plan usage estimate and measured load; no paid service provisioned without explicit authorization.
8. Review all learner-visible claims and remove placeholders, fabricated statuses and unsupported capabilities.
9. Public repository is free of signing keys, tokens, real learner progress and private attachments. Complete deployment/owner operations instructions.
10. Owner confirms the complete v1 meets the agreed scope before invitations to the group.
